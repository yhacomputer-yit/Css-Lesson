CSS Modern Units

Viewport Units

vw / vh

1vw = 1% of viewport width. 1vh = 1% of viewport height.

50vw wide
30vh tall

vmin / vmax

vmin = smaller of vw/vh. vmax = larger of vw/vh. Useful for responsive squares.

30vmin square
30vmax square
