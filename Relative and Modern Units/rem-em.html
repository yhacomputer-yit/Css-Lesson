CSS Relative Units

rem & em

rem

rem is relative to the root <html> font size. Changing html { font-size } scales everything uniformly.

This box uses rem. Small text: 0.75rem
Large text: 1.5rem

em

em is relative to the parent element font size. It compounds when nested.

This box uses em. Small text: 0.8em
Large text: 1.5em
