CSS Flexbox

Flex Grow, Shrink, Basis

flex-grow

Items grow relative to each other: flex: 1, flex: 2, flex: 3.

flex-basis

Sets the initial size before growing/shrinking: flex-basis: 100px, 150px, 200px.

flex-shrink

flex-shrink: 0 prevents an item from shrinking when space is limited.

Shorthand: flex

flex: 1 = flex-grow: 1; flex-shrink: 1; flex-basis: 0%.
