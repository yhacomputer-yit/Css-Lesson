Variables — Basics

Learn + Try

Create reusable design values and update a complete theme from one place.

How to use

Define a custom property on :root, then read it with var(--name).

Syntax
:root { --brand: #e50914; }
Example
.card { color: var(--brand); }
Result:Changing the value updates every rule that uses it.
Focus::rootvar(--name)
